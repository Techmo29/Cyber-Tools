# Home-Network

An interactive simulation of a home network designed to model routing, switching, IP addressing, and connected devices. Use it to test network layouts, traffic flow, and common home networking scenarios before changing real hardware.

## What It Simulates
- **Core Infrastructure:** Modem/WAN gateway, router, switch, and wireless access points
- **Addressing & Routing:** DHCP leases, subnetting, NAT, and packet routing between devices
- **Client Endpoints:** Laptops, phones, smart-home/IoT devices, and local storage/servers
- **Network Conditions:** Bandwidth limits, latency, packet drops, and device isolation (such as guest or IoT segments)
